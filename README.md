# Decision Trees and Random Forests

## Overview

This project implements Decision Tree and Random Forest models for Heart Disease classification using Python and Scikit-learn.

## Objectives

* Train and visualize a Decision Tree Classifier.
* Analyze and control overfitting.
* Compare Decision Tree and Random Forest accuracy.
* Identify important features.
* Evaluate models using 5-fold cross-validation.

## Tools & Libraries

* Python
* JupyterLab
* Pandas, NumPy
* Matplotlib
* Scikit-learn

## Dataset

Heart Disease Dataset.

## Key Learnings

Decision Trees, Ensemble Learning, Feature Importance, Overfitting, and Cross-Validation.
